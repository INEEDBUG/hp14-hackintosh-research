# 睡眠唤醒：尚未修复

本机 macOS 完整睡眠后，操作系统和 SSH 可以恢复，内屏仍黑。既有日志包含 HPD low、AUX 超时和 link-training 失败；这些观测定位了故障层次，尚未建立完整因果链。

## 已有对照

- `dc6config=0` 实际加载后故障仍在，这个假设不足。
- 同一面板在临时 Linux 深度睡眠后，由用户按普通键恢复内屏与命令行。
- 用户报告这台机器没有电池。Linux 对照发生在相同供电条件下，说明无电池不必然导致所有系统都无法恢复；仍不能排除某些 macOS 电源状态交互。
- 面板时序修正候选的 macOS 测试仍黑屏，已回退。
- 相似机型的平台表修改案例经本机离线字段比较后，证据不足以形成修正方案；没有作为稳定修复发布。

## 当前研究边界

固定 eDP 内屏的 HPD / AUX 处理是后续实验方向。Linux 中存在区别固定面板与可热插拔端口的处理，但移植到当前 macOS 不能只复制一个条件或吞掉真实 AUX 错误。

定制诊断曾在部分启动批次未满足观测门槛，因此有的批次只采启动日志并回退，没有执行睡眠。需要先证明日志观测点对应实际路径，才能把修正行为与物理屏幕结果关联。

本仓库不发布 Apple 系统驱动、原始反汇编或私有 KernelCollection 字节。后续可复用的自有诊断源码会在观测、许可证与发布审查完成后追加。当前没有经过实机证明的睡眠修复补丁。
