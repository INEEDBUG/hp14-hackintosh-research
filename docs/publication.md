# 公开内容与持续同步

公开材料包括项目经历、源码补丁、测试、离线构建工具、精确公共依赖版本与经过字段白名单整理的证据摘要。

保留本地的内容包括账号及验证材料、SMBIOS / ROM / 序列号等身份、个人 EFI、网络名称与地址、SSH 配置或密钥、原始日志、截图、Apple 系统二进制和原始反汇编。保留公共作者版权、合法来源与公开仓库名。

每个实质性里程碑的同步顺序：

1. 记录问题、改动、实际运行的验证及未验证边界。
2. 审查源码 / 依赖许可证和归属。
3. 在独立公开目录整理代码与白名单证据，审查暂存文件及待推送历史。
4. 运行与改动有关的测试，检查补丁应用和文档路径。
5. 提交、非强制推送，并读回确认远端提交与文件。

不逐条上传监控输出，不用定时任务消耗额度来制造进度。未验证修复不会写成完成，研究提交不会自动创建软件 Release。原始私人项目历史不复制进公开仓库。
