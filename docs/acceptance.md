# 验收条件

| 工作项 | 通过所需证据 | 当前 |
| --- | --- | --- |
| Wi-Fi 跨路由器切换 | 原生控制中心 A→B→A，无需开关无线恢复；流量确实经过无线接口 | 未完成 |
| 扫描速度 | 同一条件下记录开始、结果返回及耗时，比较基线与候选 | 未完成 |
| 连接稳定性 | 无主动切换窗口内观察，捕获首次断开触发事件，验证自动重连及实际流量 | 未完成 |
| 睡眠 | 完整系统睡眠后物理内屏、光标、输入和网络恢复，并复测 | 未完成 |
| Apple ID | 用户本地完成登录 / 验证和所需服务确认；不收集密码或身份值 | 登录 / FaceTime 已确认；其他服务按需验证 |
| AirDrop | Finder 原生 UI 与本人手机双向文件传输和内容校验 | 未完成 |
| 恢复 | 实验后确认回退文件、运行配置与可见桌面恢复 | 每个现场批次独立核验 |

离线通过的源码测试、编译、链接、接口存在、设备发现均有各自价值，不代替上表中的物理行为。偶发问题没有短时“没出错即永久通过”的判定。

现场测试需要单独安排并保留有线恢复路径；当前公开源码不自动触发任何现场操作。
